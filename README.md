<h1>Digital Library of Poems</h1>


<h2>Description</h2>
This project was for my Digital Asset Management final project and to help organize my personal poems. It consists of a relatively simple webpage built to manage digital assets (poems). The webpage allows you to view a list of poems by title and author and click on it to view further metadata like keywords,  date created, or a link to where it was found. The json file contains the collection of poems and metadata, the html files help structure the webpage, and the js files allow the webpage to function. The css file is for styling. Further improvements could be implementing a search or filter feature to allow for users to find similar poems to ones they already enjoy or to sort by date.
